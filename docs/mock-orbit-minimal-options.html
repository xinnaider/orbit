Orbit, calmer.

Three dark-minimal directions for a less polluted Orbit. All keep the core workflow: session list, populated chat, tool visibility, composer, and optional agent observability. The big move: primary screen becomes sidebar + readable chat + composer. Tokens, tasks, subagents, raw/logs, and git details move into explicit inspector surfaces.

DefaultDark minimal first. Light becomes equivalent later, not separate design.
DensityComfortable by default; compact mode available for logs and long sessions.
HierarchyChat content is primary. Telemetry becomes secondary and summoned.
MemoryOrbit should feel like a focused command room, not terminal confetti.
A

Quiet Console

Most ChatGPT-like. Wide centered conversation, generous reading width, small session sidebar, no right panel by default. Inspector is hidden behind ⌘I / button. Best if Orbit should feel calm, approachable, and legible even during busy agent runs.
