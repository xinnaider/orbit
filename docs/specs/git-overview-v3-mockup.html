  1. 01Um editor só (CodeMirror 6 + merge). View = read-only, Edit = editável — mesmo componente, zero inconsistência. Leve (sem workers do Monaco), tema orbit nativo (Atkinson/JetBrains, verde).
  2. 02Editar dentro do diff. Caret e edição na própria linha modificada (● editing · auto-save). Sem sair pro Monaco, sem trocar de tela.
  3. 03Stage por hunk. stage hunk ⌥S em cada bloco — granularidade estilo GitHub, direto no diff.
  4. 04Gutter old/new + word-level coerente com o code viewer do chat (mesma linguagem visual).
  5. 05Barra única. branch · sync · stat global + sparkline · view · ações. Nada de 4 barras empilhadas.
  6. 06Command palette ⌘P pra pular arquivo/tag; j/k navega, ⌘S salva. Usabilidade de teclado.
  7. 07Lista compacta com mini-stat, tag chip, stage no hover, seções coloridas, subpastas (bug já corrigido).
  8. 08Commit inline com contagem de staged + stage-all.
